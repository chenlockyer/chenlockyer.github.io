多机群控软件 · 组长

通过 TCP 桥接 unitree_ros2 的 wirelesscontroller 话题，基于 WirelessController 消息与 xKeySwitchUnion 位掩码做远程控制；NTP 负责多机时间同步。 集成 SSH/SFTP 快速部署与 RSA License 激活。

2026.01

G1 导览机器人

本体 Jetson 上的导航与语音导览：ROS 建图、点云转 2D 栅格、定位、路径规划， 接 RViz 点位可视化、固定点导航、语音播报与对话、上肢动作控制。 后端 Python/Flask，前端 React，点位存 SQLite。场馆侧有后台，改站点与讲解词不用找我们。

已交付 7 台设备、3 个客户；学院楼线路 13 个站点，直线约 240 米。这一套同时是本科毕业设计。

2025.09

人形机器人强化学习全身运动控制 · 组长

基于 GMR 从人体动作视频构建动作数据集，用 CSV Editor 与 savgol 平滑滤波解决 retarget 后的动作跳变；BeyondMimic 模仿学习框架训练，Isaac Lab 与 MuJoCo 做仿真训练和 sim2sim 验证，最后 sim2real 上真机。

  • 官方 unitree_rl_lab 不支持 G1 23dof 的舞蹈动作，团队补了 23dof 的 mimic 配置
  • 写动作数据裁剪脚本，把 29 维动作张量裁成 23 维（去掉腰部两个自由度）
  • 新增 23dof 训练配置，含关节名称与电机限位；补控制器 C++ 代码
  • 完成 23dof U1 型号适配，实现 mimic 舞蹈真机部署

代码已提 PR #121 到官方仓库，目前仍在 review，未合入。
