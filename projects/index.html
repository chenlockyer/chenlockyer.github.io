多机群控软件

群控 · 已交付 3 套 · 2026.05

通过 TCP 桥接 unitree_ros2 的 wirelesscontroller，配合 NTP 时间同步，把一套指令同时下发到多台 G1。支持宇树官方动作库与自编按键动作，界面里带舞蹈急停与阻尼保护。

已交付 3 个客户、3 套系统。集成 SSH/SFTP 快速部署与 RSA License 激活，从需求沟通到部署交付、售后维护走完了完整一轮。

C++ROS2TCPNTPPython

G1 导览机器人

导航 · 已交付 7 台 · 2026.01

本体 Jetson 上跑的导航与语音导览系统：雷达建图、点云转 2D 栅格、定位、路径规划，接语音讲解、对话与上肢动作。场馆侧有后台可改站点与讲解词。

已交付 7 台设备、3 个客户。学院楼那条线 13 个站点，直线约 240 米。这一套同时作为本科毕业设计。

ROSPythonFlaskReactSQLiteSLAM

人形机器人全身运动控制

强化学习 · PR 待合入 · 2025.09

基于 BeyondMimic 模仿学习框架，从人体动作视频构建数据集，retarget 到 G1 后做平滑滤波修正动作跳变，在 Isaac Lab 训练、MuJoCo 复验，最后 sim2real 上真机。

官方 unitree_rl_lab 不支持 G1 23dof 的舞蹈动作。团队补了 23dof 的 mimic 配置、动作张量裁剪脚本与控制器代码，让 23dof U1 型号能跑 mimic 舞蹈。代码已提 PR #121 到官方仓库，目前仍在 review，未合入。

腾讯 Mini 项目 · 多模态文生图自动评测

MLLM · 结项 · 2025.07

以多模态大模型作为评分模型，构建 Text-to-Image 生成任务的自动化评测体系，替代人工打分。

评测速度 168.5 用例/小时，与人类评分一致率 90.2%。担任组长，负责评测体系构建与打分方法设计。
